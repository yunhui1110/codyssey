## 확인한 내용

AI가 브라우저 자동 테스트로 확인한 결과다. 내가 직접 열어서 해 본 결과: (직접 해 보고 적기)

| 한 행동 | 기대 | 실제 |
|---|---|---|
| '기생충'을 누르고 S 글자 누르기, '타이타닉'을 A칸에 끌어 놓기 | 각각 S칸, A칸에만 있음 | 같음 |
| '괴물' 입력 후 추가 / 빈칸(띄어쓰기만)으로 추가 | 미분류에 '괴물' 카드가 생김 / 추가되지 않음 | 같음 |
| 되감기 1번 | '괴물' 카드가 사라짐 | 같음 |
| 되감기 1번 더 | '타이타닉'이 미분류로 돌아감 | 같음 |
| 앞으로 2번 | '타이타닉'이 A칸으로, '괴물'이 다시 생김 | 같음 |
| 되감기 1번 뒤 '라라랜드'를 B로 옮기기 | '앞으로'를 누를 수 없음 | 같음 |
| 새로고침 | 영화와 등급이 그대로 남음 | 같음 (되감기 기록은 새로고침하면 사라져 두 버튼이 흐리게 보임) |

| '처음으로' 뒤 되감기 | '처음으로'를 누르기 전 배치로 돌아감 | 같음 |
| 화면 폭 375px | 오른쪽이 잘리지 않음 | 같음 (버튼이 두 줄로 내려감) |
