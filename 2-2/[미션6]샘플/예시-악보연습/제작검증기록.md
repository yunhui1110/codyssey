# 제작·검증 기록: 악보 읽기 연습

> 미션 본문의 예시입니다. AI 이름과 테스트 내용은 작성 방법을 보여 주기 위한 예시입니다. 내 기록에는 실제로 쓴 AI와 실제로 본 것을 적습니다.

## 두 AI 비교

- AI A (서비스·모델 이름): 코디세이 플랫폼, 모델 A(회사 1)
- AI B (서비스·모델 이름): 코디세이 플랫폼, 모델 B(회사 2)
- 동일한 기획서와 함께 전달한 요청: “이 기획서.md대로 HTML 파일 하나를 만들어 줘. CSS와 JavaScript까지 모두 이 파일 하나에 넣고, 다른 파일이나 로그인 없이 브라우저에서 바로 열리게 해 줘. 화면 문구는 한국어로 쓰고, 기획서에 없는 기능은 넣지 마.”

| 테스트 내용 | AI A | AI B |
| --- | --- | --- |
| 12개를 모두 첫 시도에 맞히기 | 100%가 나옴 | 100%가 나옴 |
| 일부러 틀린 건반 누르기 | 정답을 알려 주지 않고 다음 음표로 넘어감 | ‘지금은 레4입니다’가 나오고 맞힐 때까지 기다림 |
| 휴대폰으로 열기 | 건반이 화면 밖으로 넘쳐 옆으로 밀어야 솔이 보임 | 건반 다섯 개가 한 화면에 보이고 누를 수 있음 |

- 선택한 결과물과 근거: B를 골랐습니다. A는 틀려도 그냥 넘어가서 어느 음을 틀렸는지 알 수 없었고, 기획서의 ‘맞힐 때까지 넘어가지 않는다’를 채우지 못했습니다. A의 악보 그림이 더 깔끔했지만, 모양은 나중에 바꿀 수 있고 틀린 음을 알려 주는 것이 이 페이지의 목적에 더 중요하다고 판단했습니다.

## 테스트 기록

| 번호 | 테스트 내용 | 예상 결과 | 실제 결과 |
| --- | --- | --- | --- |
| 1 | 12개를 모두 첫 시도에 맞히기 | 결과 화면에 100% | 예상한 대로 100%가 나옴 |
| 2 (일부러 오답 입력) | 첫 음표에서 일부러 한 번 틀린 뒤 끝까지 하기 | 92%, 틀린 건반 1회 | 100%가 나옴. 수정 기록 1로 고친 뒤 다시 해 보니 92%, 틀린 건반 1회 |
| 3 (한글 입력 상태로 테스트) | 한글 입력 상태에서 자판 A로 답하기 | 도 건반을 누른 것과 같음 | 아무 반응이 없음. 수정 기록 3으로 고친 뒤 다시 해 보니 도로 답해짐 |

## 수정 기록

### 수정 기록 1
- 발견한 문제: 첫 음표에서 일부러 한 번 틀린 뒤 끝까지 했더니(테스트 내용) 92%가 나올 줄 알았는데(예상 결과) 100%가 나왔습니다(실제 결과).
- AI에게 전달한 요청: “한 번 틀린 뒤에 맞게 누르고 끝까지 했는데 결과가 100%로 나와. 기획서에는 한 번 틀린 뒤 맞힌 음표는 첫 시도 정답에 세지 않는다고 적었어. 이 부분만 고치고, 고친 HTML 파일 전체를 처음부터 끝까지 다시 보여 줘.”
- 수정 후 테스트 결과: 같은 방법으로 다시 테스트하니 92%와 ‘첫 시도 정답 11 / 12개 · 틀린 건반 1회’가 나왔습니다. 12개를 모두 첫 시도에 맞히는 테스트도 다시 했고, 이전과 같이 100%가 나왔습니다.
- 수정 이유: 틀려도 100%가 나오면 내가 어느 음을 헷갈리는지 알 수 없고, 연습이 늘었는지도 숫자로 볼 수 없습니다.

### 수정 기록 2
- 발견한 문제: 몇 번 연습해 보니(테스트 내용) 같은 음이 연달아 나오지 않을 줄 알았는데(예상 결과) 레4가 두 번 연달아 나와, 눌렀는데 다음 음표로 안 넘어간 것처럼 보였습니다(실제 결과). 새 대화창의 AI 검토에서도 같은 지적이 나왔습니다.
- AI에게 전달한 요청: “가끔 같은 음이 두 번 연달아 나와. 기획서에는 같은 음이 연달아 나오지 않는다고 적었어. 이 부분만 고치고, 고친 HTML 파일 전체를 처음부터 끝까지 다시 보여 줘.”
- 수정 후 테스트 결과: 여러 번 끝까지 해 보니 같은 음이 연달아 나오지 않았고, 12개 안에 다섯 음이 모두 나왔습니다. 한 번 틀린 뒤 끝까지 푸는 테스트도 다시 했고, 이전과 같이 92%가 나왔습니다.
- 수정 이유: 같은 음이 연달아 나오면 넘어갔는지 알 수 없어서 같은 건반을 한 번 더 누르게 되고, 연습 흐름이 끊깁니다.

### 수정 기록 3
- 발견한 문제: 한글 입력 상태에서 자판 A를 눌렀더니(테스트 내용) 도로 답해질 줄 알았는데(예상 결과) 아무 반응이 없었습니다(실제 결과). AI 검토에서는 나오지 않은 문제입니다.
- AI에게 전달한 요청: “한글 입력 상태에서 A S D F G를 누르면 아무 반응이 없어. 기획서에는 한글 입력 상태에서도 자판으로 답할 수 있다고 적었어. 이 부분만 고치고, 고친 HTML 파일 전체를 처음부터 끝까지 다시 보여 줘.”
- 수정 후 테스트 결과: 한글 입력 상태에서 A를 누르니 도로 답해졌습니다. 영문 입력 상태에서도 전처럼 됐고, 건반을 손으로 누르는 것도 그대로였습니다.
- 수정 이유: 평소 한글 입력으로 두고 쓰는데, 연습할 때마다 영문으로 바꿔야 하면 번거롭고 처음 쓰는 사람은 고장 난 줄 압니다.

## 사용자 테스트

- 테스트 참여자와 요청한 작업: 피아노를 막 배우기 시작한 동생에게 사용법을 설명하지 않고 “이 페이지로 악보 음표를 찾아서 눌러 봐”라고 부탁했습니다.
- 사용자의 행동과 질문:
  - 금색 음표를 손가락으로 눌러 보고, 아무 일도 없자 잠시 멈췄습니다.
  - 건반 아래의 ‘A’ 글자를 보고 “이건 뭐예요?”라고 물었습니다.
- 받은 피드백: “음표 말고 건반을 누르라고 쓰여 있으면 좋겠어요.”
- 반영 내용과 결과: 제목 아래에 ‘금색 음표를 보고, 같은 음의 건반을 눌러 보세요.’라는 안내를 넣고 기획서의 ‘화면 구성과 동작’에도 이 줄을 더했습니다. 다시 써 보게 하니 바로 건반을 눌렀습니다.
