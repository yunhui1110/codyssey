|---|---|---|---|
| (AI 1) 저장 기능이 없어서 다시 열면 모든 영화가 미분류로 돌아간다 | '기생충'을 S에 놓고 '어바웃 타임'을 추가한 뒤 새로고침했더니, 기생충은 미분류로 돌아가고 어바웃 타임은 사라졌다. | 반영 | 완성 기준 "같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다"를 지키지 못한다. |
| (AI 2) '처음으로'가 직접 추가한 영화를 지우지 않는다 | '어바웃 타임'을 추가하고 '처음으로'를 눌렀더니 어바웃 타임은 사라지고 처음 영화 8개만 미분류에 남았다. AI 말과 다르다. | 보류 | 직접 해 보니 추가한 영화도 지워져서 기획서의 "처음 영화 목록과 배치로 돌아갑니다"대로 된다. |
| (AI 3) 빈 제목을 막지 않아 기획서를 어긴다 | 입력창을 비운 채 '추가'를 눌렀더니 글자 없는 카드가 생기고 안내 문구가 "‘’를 추가했어요."로 나왔다. | 반영 | 기획서는 "제목을 입력하고 ‘추가’를 누르면" 카드가 생긴다고 했다. 빈 카드는 어떤 영화인지 알 수 없어 등급을 나누는 목적에 맞지 않는다. 다만 완성 기준을 어긴다고까지 보기는 어려워 큰 문제는 아니다. |
| (AI) 이 세 가지 외에는 완성 기준을 잘 지킨다 | 창 폭을 휴대폰만큼(375px) 줄였더니 오른쪽의 "8편 중 0편 나눔"과 '처음으로' 버튼이 화면 밖으로 잘렸고, 옆으로 밀어도 움직이지 않았다. | 보류 | 완성 기준 "화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다"를 지키지 못하는데 AI가 놓쳤다. 이 부분은 내가 찾은 것으로 따로 반영한다. |
| (동료) 등급마다 색이 달라 어느 칸이 S인지 한눈에 들어온다 | S 빨강, A 주황, B 초록, C 파랑으로 칸마다 색이 달라 바로 구분됐다. | 반영 (지금대로 유지) | 직접 봐도 그렇고, 고칠 필요 없는 잘된 점이다. |
| (동료) '8편 중 3편 나눔'처럼 나와서 얼마나 남았는지 알 수 있다 | 영화 3편을 S·A·B에 옮겼더니 위에 "8편 중 3편 나눔"이 나왔다. | 반영 (지금대로 유지) | 직접 해 봐도 그렇고, 고칠 필요 없는 잘된 점이다. |
| (동료) 카드를 끌 때 칸 색이 살짝 바뀌어 어디에 놓이는지 알 수 있다 | 카드를 끌어 S칸 위에 올렸더니 칸 바탕이 연한 베이지색으로 바뀌었고, 놓으니 S칸에 들어갔다. | 반영 (지금대로 유지) | 직접 해 봐도 그렇다. 다만 색 변화가 아주 옅어서 잘 안 보일 수는 있다. |
| (동료) 휴대폰으로 열어 보니 좀 불편했다 | 무엇이 불편했는지 알 수 없어 그대로 확인할 수 없다. 창을 휴대폰 폭으로 줄였을 때는 오른쪽이 잘렸다. | 되묻기 | "휴대폰에서 어떤 동작을 할 때 불편했나요? 화면 오른쪽이 잘려서인가요, 카드를 손가락으로 끌 때인가요?" |
| (동료) 카드 옮기는 게 처음엔 좀 헷갈렸다 | 카드를 누르고 등급 글자를 누르기, 칸으로 끌어 놓기 둘 다 해 봤고 둘 다 됐다. 무엇이 헷갈렸는지는 알 수 없다. | 되묻기 | "어떤 방법으로 옮기려고 했고, 어디서 헷갈렸나요? 안내 문구를 못 봤나요, 해 봤는데 안 옮겨졌나요?" |
| (동료) 미분류가 맨 아래라 S칸까지 끌려면 화면도 같이 올려야 해 불편하다. 목록이 위나 옆에 있으면 좋겠다 | 노트북 크기 창(1280×800)에서 S칸은 화면 위쪽에 보이지만 미분류 칸은 화면 아래 밖에 있어서, 끌어 놓으려면 스크롤을 같이 해야 했다. 카드를 누르고 S 글자를 누르면 스크롤 없이 옮겨졌다. | 보류 | 직접 해 보니 끌 때는 불편한 게 맞다. 하지만 기획서가 "위에 S·A·B·C 칸, 아래에 아직 안 정한 영화"로 배치를 정해 두었고, 누르고 등급 누르기로 스크롤 없이 옮길 수 있다. |
| (동료) 카드 색이 좀 칙칙하다 | 카드는 모두 회색 계열이다. 보기에 따라 다르게 느낄 수 있다. | 보류 | 취향이라 꼭 바꿀 이유가 없고, 기획서에 색 조건도 없다. |
| (동료) 영화 포스터 사진이 같이 나오면 좋겠다 | 지금은 카드에 제목만 나온다. | 보류 | 포스터 이미지를 쓰려면 외부 파일이 필요해 완성 기준 "외부 파일이나 로그인 없이 HTML 한 장으로 열립니다"와 부딪힌다. |
| (동료) C칸은 굳이 없어도 될 것 같다 | C칸은 '아쉬움' 칸으로, 영화를 옮겨 넣을 수 있다. | 보류 | 기획서의 목적이 "본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리"하는 것이라, 아쉬운 영화를 따로 두는 칸도 필요하다. |

- 아무도 말하지 않았는데 내가 찾은 것:
  - 화면 폭을 좁히면(375px) 오른쪽의 편수 표시와 '처음으로' 버튼이 잘리고, 옆으로 밀어도 볼 수 없다. 완성 기준 "화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다"를 지키지 못한다. AI는 "세 가지 외에는 잘 지킨다"고 했고, 동료는 "휴대폰에서 불편했다"고만 했다.
  - 카드를 끌어서 왼쪽의 색깔 등급 글자(S) 위에 놓으면 옮겨지지 않고 미분류에 그대로 남는다. 오른쪽 빈 칸에 놓아야만 옮겨진다. 등급 글자가 가장 눈에 띄어서 자연스럽게 그 위에 놓게 된다.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: AI 검토는 그럴듯하게 썼지만 '처음으로' 지적은 직접 해 보니 틀렸고, 화면이 잘리는 문제는 놓쳤다. 동료들은 AI 검토의 어느 부분을 직접 확인했고 무엇을 찾았는지 비교해 보고 싶다. AI 답을 어디까지 믿고 어디부터 확인해야 하는지 기준을 세우고 싶기 때문이다.
