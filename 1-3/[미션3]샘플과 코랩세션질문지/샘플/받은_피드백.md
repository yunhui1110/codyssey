# 민수 님이 받은 피드백

민수 님이 영화 티어리스트(`민수_기획서.md`, `민수_영화티어리스트.html`)를 만든 뒤 받은 피드백 두 가지입니다.

## AI 검토

민수 님은 페이지를 만들 때 쓰던 대화가 아닌, 웹 AI 채팅의 새 대화창을 열었습니다. `민수_기획서.md`와 `민수_영화티어리스트.html`을 첨부하고 이렇게 요청했습니다.

```text
첨부한 기획서와 HTML을 비교해서, 기획서대로 안 되는 부분을 찾아 줘.
왜 그렇게 판단했는지도 알려 줘. 고치지는 마.
```

AI의 답입니다.

> 기획서와 HTML을 비교한 결과, 다음 세 가지를 보완하면 좋겠습니다.
>
> 1. **저장 기능이 없습니다.** 브라우저에 배치를 저장하는 코드가 없어서 파일을 다시 열면 모든 영화가 미분류로 돌아갑니다. 완성 기준의 ‘같은 파일을 다시 열어도 영화와 등급이 남습니다’를 충족하지 않습니다.
> 2. **‘처음으로’가 직접 추가한 영화를 지우지 않습니다.** ‘처음으로’를 누르면 처음 영화 8개는 미분류로 돌아가지만, 새로 추가한 영화는 그대로 남습니다. 기획서의 ‘처음 영화 목록과 배치로 돌아갑니다’와 다릅니다.
> 3. **빈 제목을 막지 않아 기획서를 어깁니다.** 제목을 비워 두고 ‘추가’를 누르면 글자 없는 카드가 생깁니다.
>
> 이 세 가지 외에는 기획서의 완성 기준을 잘 지키고 있습니다.

## 동료 피드백

동료 한 명이 `민수_영화티어리스트.html`을 직접 열어 써 본 뒤 남긴 의견입니다.

전체적으로 잘 만드셨어요! 좋았던 점부터 말씀드리면,

- 등급마다 색이 달라서 어느 칸이 S인지 한눈에 들어와요.
- 위에 ‘8편 중 3편 나눔’처럼 나온 덕분에 얼마나 남았는지 알 수 있어서 좋았어요.
- 카드를 끌어다 놓을 때 칸 색이 살짝 바뀌어서 어디에 놓이는지 알 수 있었어요.

아쉬웠던 점은요,

- 휴대폰으로 열어 보니까 좀 불편했어요.
- 카드 옮기는 게 처음엔 좀 헷갈렸어요.
- 카드를 끌어서 옮기는 게 불편했어요. 안 정한 영화가 맨 아래에 있다 보니, S칸까지 끌고 올라가려면 화면을 같이 올려야 하더라고요. 영화 목록이 위나 옆에 있으면 편할 것 같아요.
- 카드 색이 좀 칙칙한 느낌?
- 영화 포스터 사진이 같이 나오면 훨씬 보기 좋을 것 같아요.
- C칸은 굳이 없어도 될 것 같아요. 아쉬운 영화를 왜 넣나 싶어서요.

그래도 큰 문제는 없어서 저는 PASS 드릴게요!
