# 교육 운영 매니저 이력서

## 대상 사용자

- 교육 운영 직무에 지원하는 나와 내 경력을 확인할 채용 담당자. 컴퓨터로 읽거나 PDF로 저장해 공유하고, 휴대폰에서도 내용을 확인합니다.

## 사용 목적

- 경력과 프로젝트, 핵심 역량을 한 페이지로 정리해 내가 어떤 일을 해 왔는지 보여 줍니다.

## 화면 구성과 동작

- 맨 위에 이름, 지원 직무, 경력 요약이 있습니다.
- 왼쪽에는 연락처, 핵심 역량, 학력, 활용 프로그램이 있습니다. 오른쪽에는 최신 경력부터 두 곳의 경력과 프로젝트 두 개가 나옵니다.
- 프로젝트마다 제목 아래에 개인 제작인지 회사에서 한 일인지와 내가 맡은 역할을 적습니다.
- 컴퓨터에서는 A4 한 페이지 비율의 2단 이력서로 보이고, 좁은 화면에서는 경력·프로젝트와 추가 정보를 세로로 읽습니다.
- ‘이메일 복사’를 누르면 주소가 복사되고 ‘이메일 주소를 복사했습니다.’가 나옵니다. 자동 복사가 안 되면 주소를 직접 선택해 복사하도록 안내합니다.
- 이메일 주소를 누르면 기기에 설정된 이메일 앱으로 연결됩니다.
- ‘인쇄 · PDF 저장’을 누르면 브라우저의 인쇄 창이 열립니다. 버튼과 화면 위 안내는 인쇄물에 나오지 않습니다.

## 필요한 자료

- 이름·지원 직무·경력 요약, 이메일·거주 지역
- 회사별 근무 기간·직무·담당 업무, 프로젝트별 제작 시기·소속·내가 맡은 역할·결과
- 핵심 역량, 학력, 활용 프로그램
- 샘플에는 가상 인물 김하린의 정보를 사용하고, 하단에 가상 예시임을 표시합니다.

## 완료 기준

- HTML 파일을 열면 이름, 경력 두 곳, 프로젝트 두 개와 연락처를 읽을 수 있습니다.
- 프로젝트 두 개에서 각각 어디서 한 일인지와 내가 맡은 역할을 확인할 수 있습니다.
- ‘이메일 복사’를 누른 뒤 메모장에 붙여 넣으면 화면에 적힌 이메일과 같은 주소가 나옵니다.
- 휴대폰에서 가로로 밀지 않고 내용을 읽고 버튼을 누를 수 있습니다.
- 인쇄 미리보기에서 A4 세로·배율 100%로 설정하면 한 페이지에 들어가고, 글자가 잘리거나 버튼이 인쇄되지 않습니다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다. 사진·글꼴·라이브러리를 인터넷에서 불러오지 않습니다.

## 추가 기능

- 프로젝트 결과물을 볼 수 있는 링크
- 지원하는 직무에 따라 경력과 프로젝트를 골라 보여 주는 기능

## 한계 및 비목표

1. 화면에서 경력을 직접 입력하거나 수정할 수 없습니다. 내용을 바꾸려면 HTML을 고쳐야 합니다.
2. 이메일 복사는 주소만 복사합니다. 이메일 전송은 기기에 설정된 이메일 앱에서 합니다.
3. 경력의 사실 여부나 맞춤법을 검증하지 않습니다. 본인의 이력서로 바꿀 때는 내용과 수치를 직접 확인해야 합니다.

## 검증 방법

- 저장한 PDF를 열어 이름·근무 기간·이메일·담당 업무를 원래 자료와 항목별로 대조합니다. 빠진 내용이나 AI가 임의로 바꾼 내용이 없는지 확인합니다.
