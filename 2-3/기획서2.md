# 눈사람 눈송이 받기

## 대상 사용자

- 나 혼자 씁니다. 컴퓨터(노트북)의 웹 브라우저에서 키보드로 합니다.

## 사용 목적

- 프로그램 설치나 파일 내려받기처럼 로딩을 기다리거나 인터넷 연결이 안되는 동안, 45초짜리 게임 한 판으로 기다리는 시간을 보냅니다.

## 화면 구성과 동작

- HTML 파일을 열면 게임이 바로 시작되지 않고, 화면 가운데에 ‘눈사람 눈송이 받기’ 제목과 ‘시작’ 버튼이 나옵니다. (수정하며 바꿈)
- ‘시작’ 버튼을 누르기 전에는 눈송이가 떨어지지 않고, 남은 시간도 45초에서 줄어들지 않으며, ← → 키를 눌러도 눈사람이 움직이지 않습니다. (수정하며 바꿈)
- ‘시작’ 버튼을 누르면 버튼이 사라지고 45초짜리 한 판이 시작됩니다. (수정하며 바꿈)
- 화면 맨 위 왼쪽에 ‘남은 시간 45초’, 오른쪽에 ‘받은 눈송이 0개’가 보입니다.
- 화면 아래쪽 가운데에 눈사람이 서 있습니다. 눈사람은 사진 없이 도형(흰 동그라미 두 개, 검은 눈, 주황색 코)으로 그립니다.
- 눈송이는 화면 위쪽의 무작위 가로 위치에서 나타나 아래로 떨어집니다. 나오는 간격은 0.5초에서 1.5초 사이에서 매번 무작위로 정해져, 평균 약 1초에 하나씩 나옵니다. (수정하며 바꿈)
- 눈송이마다 떨어지는 속도가 조금씩 다릅니다. 같은 순간에 나온 눈송이라도 어떤 것은 조금 빠르고 어떤 것은 조금 느립니다. (수정하며 바꿈)
- 남은 시간이 줄어들수록 눈송이가 떨어지는 속도가 서서히 빨라집니다. 0초 직전에는 시작할 때보다 약 2배 빠르게 떨어집니다. 나오는 간격은 빨라지지 않습니다. (수정하며 바꿈)
- 키보드 ← 키를 누르고 있는 동안 눈사람이 왼쪽으로, → 키를 누르고 있는 동안 오른쪽으로 움직입니다. 키에서 손을 떼면 멈춥니다.
- 눈사람은 화면 왼쪽 끝과 오른쪽 끝 밖으로 나가지 않습니다.
- 눈사람은 화면 반대쪽 끝에서 나온 가장 빠른 눈송이도 받을 수 있는 속도로 움직입니다. 속도는 화면 크기에 맞춰 정해지고, 한 판 동안 바뀌지 않습니다. (수정하며 바꿈)
- 눈송이가 눈사람에 닿으면 그 눈송이가 사라지고 ‘받은 눈송이’ 숫자가 1 늘어납니다.
- 눈사람에 닿지 않고 바닥까지 떨어진 눈송이는 그냥 사라지고, 숫자는 변하지 않습니다.
- 남은 시간은 1초마다 1씩 줄어듭니다.
- 남은 시간이 0초가 되면 눈송이가 더 나오지 않고 눈사람도 움직이지 않습니다. 화면 가운데에 ‘끝! 받은 눈송이 ○개’와 ‘다시 하기’ 버튼이 나옵니다.
- ‘다시 하기’를 누르면 남은 시간 45초, 받은 눈송이 0개로 돌아가 새 판이 바로 시작됩니다. 눈송이 속도도 다시 처음 속도로 돌아갑니다. (수정하며 바꿈)

## 필요한 자료

- 외부 자료(사진, 글꼴, 라이브러리, 효과음)는 사용하지 않습니다. 눈사람과 눈송이는 HTML 안에서 도형으로 직접 그립니다.
- 화면에 들어갈 글: ‘눈사람 눈송이 받기’, ‘시작’, ‘남은 시간 ○초’, ‘받은 눈송이 ○개’, ‘끝! 받은 눈송이 ○개’, ‘다시 하기’

## 필수 기능

- ‘시작’ 버튼을 누르면 시작되는 45초짜리 한 판 (수정하며 바꿈)
- ← → 키로 눈사람을 좌우로 움직이기
- 무작위 간격과 조금씩 다른 속도로 떨어지는 눈송이 (수정하며 바꿈)
- 남은 시간이 줄어들수록 빨라지는 눈송이 (수정하며 바꿈)
- 떨어지는 눈송이를 받으면 1개씩 세기
- 남은 시간과 받은 눈송이 수 표시
- 끝난 뒤 결과 표시와 ‘다시 하기’

## 완료 기준

- HTML 파일을 열면 ‘시작’ 버튼이 보이고, 아무것도 누르지 않고 10초를 기다려도 눈송이가 떨어지지 않으며 남은 시간이 45초 그대로입니다. (수정하며 바꿈)
- ‘시작’ 버튼을 누르기 전에 ← → 키를 눌러도 눈사람이 움직이지 않습니다. (수정하며 바꿈)
- ‘시작’ 버튼을 누르면 버튼이 사라지고, 눈송이가 떨어지기 시작하며, 남은 시간이 45초부터 줄어듭니다. (수정하며 바꿈)
- → 키를 누르고 있으면 눈사람이 오른쪽으로 움직이고, 손을 떼면 멈춥니다. ← 키도 같은 방식으로 왼쪽으로 움직입니다.
- → 키를 계속 누르고 있어도 눈사람이 화면 오른쪽 밖으로 사라지지 않습니다. ← 키도 마찬가지입니다.
- 남은 시간이 5초쯤 남았을 때 눈사람이 한쪽 끝에 있고 눈송이가 반대쪽 끝에서 나와도, 그쪽 방향키를 계속 누르고 있으면 눈송이가 바닥에 닿기 전에 받을 수 있습니다. (수정하며 바꿈)
- 한 판을 지켜보면 눈송이가 나오는 간격이 일정하지 않습니다. 두 개가 거의 붙어서 나올 때도 있고, 1초 넘게 나오지 않을 때도 있습니다. (수정하며 바꿈)
- 한 판을 지켜보면 비슷한 때에 나온 눈송이끼리도 떨어지는 속도가 조금씩 다릅니다. (수정하며 바꿈)
- 마지막 10초에 떨어지는 눈송이가 처음 10초에 떨어지는 눈송이보다 눈에 띄게 빠릅니다. 녹화 영상에서 처음 나온 눈송이 하나와 마지막 즈음 나온 눈송이 하나가 화면 위에서 바닥까지 가는 시간을 재면, 마지막 눈송이가 절반 정도의 시간에 도착합니다. (수정하며 바꿈)
- 눈송이 하나를 눈사람으로 받으면 그 눈송이가 사라지고 ‘받은 눈송이’ 숫자가 정확히 1 늘어납니다. 눈송이가 빨라진 마지막 10초에도 같습니다. (수정하며 바꿈)
- 눈송이를 받지 않고 바닥에 떨어뜨리면 ‘받은 눈송이’ 숫자가 변하지 않습니다.
- ‘시작’ 버튼을 누를 때 휴대폰 스톱워치를 함께 시작하면, 스톱워치가 44~46초일 때 ‘끝!’ 화면이 나옵니다. (수정하며 바꿈)
- ‘끝!’ 화면이 나온 뒤에는 ← → 키를 눌러도 눈사람이 움직이지 않고 숫자도 변하지 않습니다.
- ‘끝!’ 화면의 눈송이 개수가 화면 위쪽에 표시된 ‘받은 눈송이’ 개수와 같습니다.
- ‘다시 하기’를 누르면 남은 시간이 45초, 받은 눈송이가 0개로 돌아가고, 눈송이가 다시 처음의 느린 속도로 떨어집니다. (수정하며 바꿈)
- ‘시작’을 누른 뒤 아무 키도 누르지 않고 45초를 그대로 두어도 오류 없이 ‘끝!’ 화면이 나옵니다. (수정하며 바꿈)
- 다른 파일이나 로그인, 인터넷 연결 없이 HTML 파일 하나로 열립니다.

## 추가 기능

- 휴대폰에서 할 수 있도록 화면에 ◀ ▶ 터치 버튼 넣기
- 최고 점수를 브라우저에 저장해 다음에 열었을 때 보여 주기
- 받으면 점수가 깎이는 방해물(고드름)
- 눈송이를 받을 때 나는 효과음
- ‘쉬움·보통·어려움’처럼 난이도를 직접 고르는 기능

## 한계 및 비목표

1. 컴퓨터 키보드로만 조작합니다. 휴대폰이나 태블릿의 터치 조작은 이번에 만들지 않습니다.
2. 점수와 최고 기록을 저장하지 않습니다. 창을 닫거나 ‘다시 하기’를 누르면 이전 결과는 사라집니다.
3. 난이도는 남은 시간에 따라 눈송이 속도가 자동으로 빨라지는 것 한 가지뿐입니다. 사용자가 난이도를 고를 수 없고, 방해물도 없습니다. (수정하며 바꿈)

## 검증 방법

- 컴퓨터의 화면 녹화 기능으로 한 판을 ‘시작’ 버튼을 누를 때부터 ‘끝!’ 화면까지 녹화합니다. 녹화 영상을 느리게 돌려 보며 눈사람에 닿아 사라진 눈송이를 직접 세고, 그 수를 ‘끝!’ 화면에 표시된 ‘받은 눈송이 ○개’와 비교합니다. 두 수가 같으면 통과입니다. (수정하며 바꿈)
