## 두 AI 비교

- AI A (서비스·모델 이름): ChatGPT
- AI B (서비스·모델 이름): Claude Code
- 동일한 기획서와 함께 전달한 요청: “이 기획서.md대로 HTML 파일 하나를 만들어 줘. CSS와 JavaScript까지 모두 이 파일 하나에 넣고, 다른 파일이나 로그인 없이 브라우저에서 바로 열리게 해 줘. 화면 문구는 한국어로 쓰고, 기획서에 없는 기능은 넣지 마”

| 테스트 내용 | AI A | AI B |
| --- | --- | --- |
| 파일을 열어 화면 디자인 보기 | 폰트가 안예쁨 | 디자인이 보기 좋았음 |

- 선택한 결과물과 근거: B(Claude Code). 디자인과 눈송이 모양이 마음에 들었고, 창 폭을 줄여도 글자가 잘리지 않았습니다.
- 선택한 파일: `눈사람_눈송이받기 v1.html`

## 수정 기록

### 수정 기록 1 (v1 → v2)
- 발견한 문제: 파일을 열면(테스트) 준비한 뒤 시작할 줄 알았는데(예상) 열자마자 게임이 시작돼 버렸습니다(실제).
- AI에게 전달한 요청: “화면을 켜자마자 시작하지 않고. Start버튼을 누르면 시작할 수 있도록 버튼을 생성해줘.”
- 수정 후 테스트 결과: 열면 ‘시작’ 버튼이 나오고, 누르기 전에는 시간이 45초에 멈춰 있고 눈사람도 안 움직였습니다. 누르면 바로 시작됐고, 끝 화면과 ‘다시 하기’도 전과 같았습니다.
- 수정 이유: 키보드에 손을 올리기 전에 게임이 시작되면 처음 몇 초를 그냥 놓칩니다.

### 수정 기록 2 (v2 → v3)
- 발견한 문제: 한 판을 해 보니(테스트) 눈송이가 예측하기 어렵게 떨어질 줄 알았는데(예상) 너무 일정하게 떨어졌습니다(실제).
- AI에게 전달한 요청: “눈 송이가 너무 일정하게 떨어지는데 랜덤하게 떨어지도록 해.”
- 수정 후 테스트 결과: 눈송이가 0.5~1.5초 사이 들쭉날쭉한 간격으로, 서로 조금씩 다른 속도로 떨어졌습니다. 점수와 끝 화면은 전과 같았습니다.
- 수정 이유: 같은 박자로 떨어지면 금방 지루해집니다.

### 수정 기록 3 (v4 → v5)
- 발견한 문제: 끝 무렵 눈송이가 빨라졌을 때, 눈사람 반대쪽 끝에서 나온 눈송이를 향해 방향키를 계속 눌러 보니(테스트) 받을 수 있을 줄 알았는데(예상) 도착하기 전에 바닥에 떨어졌습니다(실제).
- AI에게 전달한 요청: “눈사람 이동속도가 너무 느려서 눈송이가 빠르게 내려오면 양 끝에 눈은 물리적으로 받을 수 없게되었다. 이 부분을 수정해줘. 수정할때 기존에 기획했던 다른 부분들을 임의로 수정하거나 바꾸지마”
- 수정 후 테스트 결과: 같은 상황에서 여러 화면 크기로 해 보니 양 끝 눈송이도 받을 수 있었습니다. 시작 버튼, 무작위 낙하, 점수, 끝 화면은 전과 같았습니다.
- 수정 이유: 아무리 빨리 움직여도 못 받는 눈송이가 있으면 게임이 불공평하게 느껴집니다.
